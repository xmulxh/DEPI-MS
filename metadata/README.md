# Metadata

- five_fold_cv_patient.xlsx: participant-level five-fold split for the internal NPC cohort. Each Fold1-Fold5 sheet contains train_id and val_id.
- waibu_five_fold_cv.xlsx: external validation list. Each Fold1-Fold5 sheet contains the same 48 external sample IDs in val_id so that each internal fold model is evaluated on the full external cohort.
- peak_table_example.csv: three-row example feature table showing the columns used for RT-m/z hotspot matching.
